# TacticalShooter builds

This repo only holds the game files. The game checks here when it starts and updates itself.

**New player (Mac):**
1. Open the [Full download](../../releases/tag/install) release and download `TacticalShooter-mac.zip`.
2. Unzip it and drag **TacticalShooter** into your **Applications** folder.
3. The first time, right-click it and choose **Open** (it isn't from the App Store).
4. If the menu says **UPDATE AVAILABLE**, press **UPDATE NOW**.

**New player (Windows):**
1. Open the [Full download](../../releases/tag/install) release and download `TacticalShooter-windows.zip`.
2. Right-click the zip, choose **Extract All**, and put it somewhere like **Documents** (not Program Files, or it can't update itself).
3. Open the **TacticalShooter** folder and run **TacticalShooter.exe**. If Windows says it protected your PC, click **More info**, then **Run anyway** (it isn't from the Microsoft Store).
4. If the menu says **UPDATE AVAILABLE**, press **UPDATE NOW**.

**Already playing:** just open the game. When there's a new version the menu shows **UPDATE NOW**; it downloads only what changed and restarts. You and your friends need the same version to play together, and Mac and Windows players can play together.
